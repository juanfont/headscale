## Verdict in five lines

1. Kit v1 reproduces: every adapter is 112/112 MUST, STRETCH as each champion said (urfave 0/4, others 4/4).
1. Kit v2 (155 MUST) separates them: own-grammar and own-pflag 155; creachadair 149; cobra 148; kong 148; urfave 146.
1. Every MUST failure except urfave's was fixed in 1–8 lines using the framework; kong's A01 needed a
   workaround and exposed a latent bug. urfave's failures cannot be fixed inside urfave's completion: it
   took replacing its scripts (+96/−51 lines).

   from the champions, one new: bash corrupts `tag:ci,tag:p`); the `--flag=value` form was broken in
   four of six delivered adapters.

## 1. Shell table: what a user gets

How: each binary is on `PATH` as `headscale`; its own `headscale completion <shell>` output is loaded;
cwd holds `other.json` and `policy.hujson`. bash, zsh and fish run interactively in a pty; the line
is typed, Tab pressed once, the edited line read back (a trailing space is visible). fish lists come
from `complete -C`, PowerShell from `TabExpansion2`. The urfave binary as delivered routed
`headscale completion --generate-shell-completion` to its script printer (a harness artefact of its
`main.go`); the referee rebuilt it with that one line changed (`shell/build-urfave-delivered`).

Legend: `word␣` completed with a space; `word` completed, no space; `{a b …N}` listed (N in all);
`files` the two test files offered; `∅` nothing; `ERR` the shell printed an error into the terminal;
`THROWS` PowerShell's completer threw (`TabExpansion2` error; what an interactive console shows was
not checked); `~x` the line was rewritten (bash shows `\,` escapes).

## 4. Cheating and fairness

- **No special-casing found.** No adapter contains case IDs, argv strings from the suite, `os.Args`
  reads in `Run`/`Complete`, `unsafe`, or reflection on framework internals (kong's `reflect` builds
  struct types; it reads kong only through exported API). The only kit names in adapters are `help`
  and `kit.Program`, which the README requires. `spikes/kit/*.go` mtimes (14:51–14:56) predate
  every adapter; checksums unchanged during this run.
- **Undeclared argv handling: none material.** One side effect not stated: creachadair's `--` split
  cuts at the first `--` even when it is a flag's value (`--name --` → missing-value, O02).
- **The kit overrated urfave.** `Complete` was driven in-process, and urfave's adapter reports
  `Files` for every empty answer, which is what bash and zsh do and the opposite of fish. Kit v1 had
  no case that forbids files; v2 does (urfave fails N08, N09, N11). The fish half is visible only in
  a shell.
- **D15–D18 postdate the adapters.** The four framework adapters list aliases because kit v1's C05
  required alias completion and nothing forbade extras; their D16 failures are not champion errors
  and cost 4–5 lines each (urfave excepted, above). own-\* already implemented the D16 rule.
- **Does `Exec` doing the refusals hide real work?** For `Run`, no: in 001 the builder does these
  checks for every framework, so the adapter would not do them in Headscale either. It hid two things
  on the Tab path, where `Exec` never runs: the flag set per command (v2 N15–N18; cobra's root `-o`
  failed) and file policy (v2 N08–N14). It also hid that the adapter must deliver every occurrence
  and given-ness, which every adapter paid for with a custom value type (counted in its lines).
- **The kit cannot see the protocol.** The `--x=value` form, `NoSpace` and script bugs live between
  the binary and the shell. Four of six delivered adapters were broken on `--x=value` (cobra in fish, urfave, kong,
  creachadair) with every kit row green.
- **Cobra script bugs, against stock cobra** (`spikes/v2/stock-cobra`: cobra v1.10.2 + pflag v1.0.10,
  Headscale's versions, no adapter; and the same program against cobra `adbc881`, main):

## 5. Ranking

The evidence ranks them; the maintainer picks.

1. **own-grammar ≈ own-pflag (tie on behaviour).** The only adapters that passed kit v2 as
   delivered (155/155) and the best completion in three shells: a space after finished words, none
   inside a comma list, the `--x=value` form working everywhere (fish thanks to a one-line script
   patch). No third-party behaviour is relied on. own-grammar has fewer lines (228 vs 254) and no
   workaround; own-pflag spends its 16 WA lines switching pflag off. Cost: we own 1,143 lines of
   cobra's shell scripts (they carry the bash `\,` and colon+comma bugs) and a parser.
1. **kong ≈ creachadair (tie).** kong ends at 155 · 12/12 but needed the most fixing (A01
   workaround, latent empty-value bug, `--x=`), rests on trace-position rules, uses `reflect.StructOf`
   and adds one module. creachadair ends at 155 · 10/12 with 4 fix lines and no new module, but reads
   error kinds from four message texts, accepts `-output`/`--o`, and its root takes `-h`/`-o`/`-c`
   anywhere, even as another flag's value. Both borrow Tailscale's frozen tempfork scripts, which
   behave better in bash than cobra's current ones.
1. **cobra.** 155 after 13 lines of framework use; zero migration and no new module (pflag bump to
   v1.1.0). Behind kong and creachadair because the D11 refusals are missing (8/12; a pre-scan to
   add), it has the most workaround lines (~42), and its own scripts show three bugs in real shells
   that wait on upstream or a fork.
1. **urfave.** As a completion framework it cannot meet D16 or the file rules: fixing that meant
   replacing its completion. As a parser behind borrowed scripts it reaches 155 · 9/12, with error
   kinds from message text and a package-global help switch.

Between 1 and 2 the question is not parsing (all reach 155) but who keeps the shell scripts:
us (own-\*, cobra's newest scripts, patched) or Tailscale's tempfork (kong, creachadair, fixed
urfave). That is open question 1.

What the referee could not measure:

- PowerShell in an interactive console (only `TabExpansion2`); whether its `THROWS` shows anything.
- Descriptions: the kit tree has none.
- macOS bash 3.2 without bash-completion, Windows, zsh menu-select styles, other zsh frameworks.
- The real tree (~50 commands) and real specs; numbers here are on the kit's 12 leaves.
- Upgrade behaviour over time: the "unpromised behaviour" row lists where it would break, not that it will.
