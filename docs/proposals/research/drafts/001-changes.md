### 001, the decisions and the built code disagree, not settled

- **Conflict A** (D41 "no strings to the caller" against D35 and Tab): the library keeps the text of every flag in `Line.Flags`. 001 no longer says what the parser returns, so it takes no side. It is 003's point.
- **The aliases are not built.** `spikes/final-typed/headscale/specs.go` writes `cmdline.Opt[string]` and `cmdline.Path`. A generic alias needs Go 1.24; the module is on 1.27.
- **`command.Owner` and the list rules.** As a late reader, an owner is not checked while the line is read (design call 18). `auth keys create tag:a,,tag:b` is then refused at the lookup, after the client is made, and not at its place on the line as the table in "Errors on the command line" says for "empty item in a list argument". - **How a spec says where it stands in the tree.** The spike's `Spec` has `Path: "nodes routes set"`. 001 had `Use: "set <node> <routes>"` and has `Name: "set"`; neither says how the groups are given. Not decided, not in 001.
