# The rules of the typed build

Date: 2026-11-18. Input for the writer of `docs/proposals/003-cmdline.md`. This file is complete for
the typed build in `spikes/final-typed/` (D41–D49). It replaces `rules.md`, which stays as the
record of the string-only build in `spikes/final/`.

Every rule of `rules.md` is here under its old number, with a status: **same**, **changed** (the
text is the new one), **moved to the library** (it was Headscale's layer, now the library does it)
or **removed**. New rules have new letters and numbers.

111 old rules: 73 the same, 31 changed, 6 moved to the library, 1 removed. 45 new rules. 155 rules in all.

## How to read the rules

- **Source**: as in `rules.md`. New: `D41`–`D49` the typed decisions; `the brief` the task the
  typed build was made from (`typed-library.md`, "The task"); **`call 4`** a call made while
  building the typed layer, not confirmed by the maintainer (listed at the end, and with its
  alternative in `typed-library.md`). **`open`** as before.
- **Held by**: `P07`, `T34`, `O3`, `K4`, `S01` are rows of the reader's tests, now in
  `cmdline/internal/reader/reader_test.go`, with the numbers they had. A row named by a rule
  (`Y1 rows of TestValues`) is in `cmdline/cmdline_test.go`: the first field of each table row is
  the rule it holds. `kit:H14` is a row of kit v4: the rows of kit v3, of which four now use
  `json` as the value of `-o` (E22, H20, P06, P11), and thirteen new rows for D49 (J01–J13).
  `corpus:…`, `FuzzRun`, `FuzzLeaf`, `FuzzTab`, `sh:"…"` as before, now under `spikes/final-typed/`.
  `toy` is `spikes/final-typed/toy/main_test.go`.
- Terms. **The reader**: the string reader of the old build, now the internal package
  `cmdline/internal/reader`. **The library**: the package `cmdline` with the reader under it.
  **The input struct**: the type `In` of a `Command[In]`. **A struct of flags**: a struct type
  listed in `Flags` of a `Group` or a `Command`. **Late**: read by a `LateReader`. The other terms
  are those of `rules.md`.

## Rules that are still open

The four open points of `rules.md` stand (X4, X2, X3, K3/K4). The typed build adds these calls,
which nobody has confirmed. Each is in `typed-library.md` with the alternative.

1. **Y1** numbers are decimal only (other: Go's prefixes `0x`, `0o`, `0b` and `_`).
1. **Y4** a named type must say how it is read (other: read every type by its kind, so
   `type ID uint64` needs no method, and `time.Duration` without a Reader reads `5` as 5 ns).
1. **Y9, K14** defaults are a `default` tag (other: no defaults in the library; the command sets
   them in `Run`, as 001 does today for the expiry of a key).
1. **K11** a tag key that the library does not know is refused, also `json` (other: only keys
   that look like a misspelling).
1. **K18** one struct type per flag name in a group's scope (other: fill every struct that declares
   the name).
1. **R5, R6 in the library**: a `[]T` never takes an empty list or an empty item. A program that
   wants "empty means clear" cannot use `[]T` for that flag (other: a knob, which the library has
   none of).
1. **G6, G7** a line runs once, and a Line that `Parse` did not make does not run; both return
   an error (other for G6: run again, without the lookups, as the first build did).
1. **K19** the order of the problems in the error of `New` (other: no promise about the order).
1. **Y9** a `Repeat` may have a default (other: refuse it, as for `Opt`).
1. **M1** `Line.Flags` and `Line.Args` still hold the text as typed (other: positions only). D41
   says the library hands no strings to the caller; D35 and the Tab rule T14 need them.

Settled since the build: flags of a layer above as structs in `Flags`, read with `Get` (D48); a
strict `Format` for `--output` (D49, rule R7).
