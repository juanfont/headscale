### Exported API (`go doc -all`, comments shortened to the field lines)

```text
package cmdline // import "spike/cmdline"

func Check(root *Command) error
func Serve(w io.Writer, root *Command, args []string) bool
type Command struct {
	Name     string
	Aliases  []string
	Help     string      // one line; Tab shows it next to the name
	Flags    []Flag
	Args     []Completer // Tab for the n-th positional; nil entries offer nothing
	Commands []*Command
}
type Completer func(line *Match, prefix string) ([]string, Directive)
    func Words(words ...string) Completer
type Directive int
    const Failed, NoSpace, NoFiles, FilterExt, FilterDirs, KeepOrder Directive = 1, 2, 4, 8, 16, 32
    func Complete(root *Command, words []string, cur string) ([]string, Directive)
    func Files(*Match, string) ([]string, Directive)
type Error struct {
	Kind ErrorKind
	Path []string // the command reached, as in Match.Path
	Word string
	At   int      // the index in argv of the word
}
    func (e *Error) Error() string
type ErrorKind int
    const UnknownCommand, UnknownFlag, MissingValue ErrorKind = 1, 2, 3
type Flag struct {
	Name     string    // long name, without dashes
	Short    rune      // one letter, or 0
	Bool     bool      // takes no value: "--x" reads "true", "--x=v" reads "v"
	Repeat   bool      // Tab offers it again once given; Parse keeps every occurrence of every flag
	Help     string    // one line; Tab shows it next to the name
	Complete Completer // Tab for the value; nil offers nothing, Files offers file names
}
type Given struct {
	Name  string // the flag's long name, whatever spelling was typed
	Value string // as typed; "true" for a bool given bare
	At    int    // the index in argv of the flag word
}
type Match struct {
	Command *Command
	Path    []string // names from the root (not aliases), root excluded
	Flags   []Given  // every flag given, in the order typed
	Args    []string // positionals, in order
	ArgAt   []int    // the index in argv of each positional
}
    func Parse(root *Command, argv []string) (*Match, error)
    func (m *Match) Values(name string) []string

package script // import "spike/cmdline/script"
func Write(w io.Writer, shell, program string) error
```

New in round two: `Check`, `Given`, `Match.Values`, `Match.ArgAt`, `Error.At`; `Match.Flags`
changed from a map to the ordered `[]Given` (D35); `Parse` now returns the partial Match next to
an error. No compatibility promise while the package lives in Headscale's repository (call 2).

## How to read the rules

- **Source**: `Dn` a decision in `DECISIONS.md`; `facts` its "Facts fixed without a question";
  `call 1` its "Calls made by the assistant"; `call 2` its "Second set of calls by the assistant"
  (not confirmed by the maintainer; this covers every rule the first round listed as nobody's
  decision); `001 Lnnn` a line of `001-cli.md`, `001 Qn` an open question of its draft;
  `requirements Rnn` a row of `requirements.md`; `upstream` pflag/cobra/POSIX behaviour no
  Headscale text states; **`open`**: settled here to make D35 exact, not yet confirmed by anyone
  (listed at the end).
- **Held by**: `P07` a row of `TestParse`, `T34` of `TestComplete`, `O3` of `TestOrder`, `K4` of
  `TestCheck`, `S01`–`S05` the checks in `TestServe`/`TestPure`/`TestContract` (all
  `cmdline/cmdline_test.go`); `kit:H14` a kit v3 row; `corpus:pflag-034`; `FuzzRun`, `FuzzLeaf`,
  `FuzzTab`, `FuzzParse` (property named); `sh:"…"` a line of `headscale/shell/lines.txt`.
- Terms. **Flag word**: L1. **Group**: a command with at least one child; **leaf**: one with
  none. **Scope**: the flags readable at a group (W1). **Typed name**: a flag word up to its first
  `=`. **Position** of a word: its index in argv. **The layer**: Headscale's code on top of the
  library (here `headscale/adapter.go` and the kit's `Exec`, which stands for 001's builder).

111 rules in 12 groups. Every rule has a test except E7 and E8, which the kit does not model.
5 rules carry an **open** part (X2, X3, X4, K3, K4), listed at the end.

Where "leftmost" needed a choice (the **open** parts above):

1. **A wrong count** has no word ("too few") or several candidates ("too many": the first extra
   positional, or the last). Settled as the whole line, after every other mistake (X4). The other
   choice, the first extra positional, would make `nodes delete 12 13 --force=maybe` a count error
   and would need `--help` to be known before the parser has read it.
1. **not-alone** is a pair of words; settled at the second of the two (`--version -c x`: at `-c`;
   `-c x --version`: at `--version`). The other choice: always at `--version`.
1. **Several kinds in one word** (X3): settled in the order the layer checks them.
1. **A flag before the subcommand that the leaf does not take**: its mistake stands where the flag
   stood (X2), so `-c a -o j -c b check config` reports `-o`, not the repeat of `-c`.
1. **Tab** has no positions: it reports nothing, it skips (T1).
